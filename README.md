# GameSim

A three-agent coaching team for Pokémon Champions: the **Scout** (research), the **Coach** (game review), and the **Lab**
(new strategies). It's built from the master prompt in
[`prompts/champions-coaching-team.md`](prompts/champions-coaching-team.md).

## Start here
- **Your first quiz:** [`trainer/film-study/2026-09-28-baseline.md`](trainer/film-study/2026-09-28-baseline.md)
- **How to send games:** [`trainer/README.md`](trainer/README.md)
- **The current Singles meta:** [`knowledge/meta/singles/brief-2026-09-28.md`](knowledge/meta/singles/brief-2026-09-28.md)
- **The Lab's first team idea:** [`lab/hypotheses/z-guard-balance.md`](lab/hypotheses/z-guard-balance.md)

## Layout
| Folder | What's in it |
|---|---|
| `.claude/agents/` | The three agent definitions |
| `knowledge/` | Rules, mechanics, sources, meta briefs, events, player dossiers, and the Film Room |
| `trainer/` | Your profile, games and reviews, practice plan, and film study |
| `lab/` | Strategy hypotheses, forecasts, and the playbook of tested ideas |
| `tools/` | Helpers: frame extraction from your recordings, Showdown replay reader |
